HOTEL MANAGEMENT SYSTEM

Run in VS Code terminal from the hotelmanagement folder:

1. Install packages:
   python -m pip install -r requirements.txt

2. Start server:
   python -m uvicorn backend.main:app --reload

3. Open:
   http://127.0.0.1:8000/docs

The frontend can be opened from frontend/index.html after the server is running.
